## 第 5 项 · 部署失调与「每单位每回合一次行动」（设计文档 §7.1）

Kards 官方口径："Without Blitz, you need to wait one turn after the deployment
until you **use** the unit." —— 是 use 不是 attack，所以部署当回合**既不能移动也不能攻击**；
要走到敌方 HQ 需要三个己方回合（部署 → 移动上前线 → 攻击）。

- 用例种子：**1**（开局手上就有可打出的单位卡）
- 部署：成功 → 侦察兵（1/2，行动费 1 点）
- 落点：Line.Support，SupportLine.Count = 2
- 部署当回合 CanUnitAttack：False（本回合刚部署，处于部署失调）
- 部署当回合 CanUnitMove：False（本回合刚部署，处于部署失调）
- 部署当回合直接调 MoveUnit 被拒：True

- 推进一个完整轮次后（HalfTurn=3）CanUnitMove：True
- 移动结果：True，Line = Front，前线归属 = 0（-1 = 无人占领）
- 移动前后**资源**：2 → 1（期望扣 1）
- 移动后本回合 CanUnitAttack：False（期望 false：该单位本回合已经行动过）

**结论：部署当回合既不能移动也不能攻击（部署失调成立）；下一回合可移动、扣除的资源与行动费一致，且移动后本回合不能再攻击（「每单位每回合一次行动」成立）。**

### 8.4 疲劳结算（牌库空后的第 k 次结束回合扣 2^k）

只清空**我方**牌库，然后推进回合。关键口径：牌库空 → 不抽牌、**不判负**，
改成「自己每次回合结束扣 2^k」，且**各方独立计数**（对手牌库没空就完全不受影响）。

| 次数 | 期望伤害 | 实测伤害 |
|---|---|---|
| 第 1 次 | 2 | 2 |
| 第 2 次 | 4 | 4 |
| 第 3 次 | 8 | 8 |

| 检查 | 结果 |
|---|---|
| 伤害序列 = 2 / 4 / 8 | ✅ |
| 牌库空后不再抽牌（手牌数不变） | ✅ |
| 对手牌库没空 ⇒ 完全不受疲劳影响 | ✅ |
| 一直推下去会由疲劳击破 HQ 而终局（2+4+8+16 = 30 > 20） | ✅ |

**结论：HQ 作为后线单位的一切行为（占位 / 不可行动 / 不可被指令指定 / 只有前线能打 / 不反击）与疲劳的「不抽牌 + 2^k + 各方独立 + 统一判负」全部符合设计文档 §6.1.2 / §5.2.1。**
